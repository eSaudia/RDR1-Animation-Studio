# RDR1 Animation Studio v0.9.0 — game-wide animation browser and Blender workflow

I’m releasing RDR1 Animation Studio, an independent Windows utility for Red Dead Redemption animation modding.

It scans the complete game directory, indexes animation sets, keeps exact resource names/source paths, identifies duplicate motion by decoded data, and lets you preview supported clips on a real skinned character before export. Selected clips or the entire library can be exported to Blender. Edited Blender actions can be imported into a new validated WAS file without modifying the original archive.

The app includes a dark mode, RDR1-themed icon, scan report, and credits eSaudia.

Requirements: Windows 10/11 x64, .NET 10 Desktop Runtime, Blender 3.6+, Python 3.12, and WebView2 Runtime.

Download: attach `RDR1-Animation-Studio-v0.9.0-win-x64.zip`.

Please report the exact source archive, animation name, and validation report when reporting a problem. This is an early experimental importer; always back up game files.
